# 🌐 Personal Portfolio Website

This is a responsive and modern **personal portfolio website** built using **HTML and CSS**. It showcases professional details, technical skills, projects, certifications, and contact information in a clean and minimal UI.

---

## 🚀 Features

* 🎯 Clean and modern dark-themed UI
* 📱 Fully responsive design (mobile-friendly)
* 👨‍💻 About Me section
* 🛠️ Technical Skills display with tags
* 📂 Projects section with interactive cards
* 📜 Certifications section
* 📈 "Currently Exploring" section
* 📞 Contact information with links
* ✉️ Feedback form (UI only)

---

## 🧰 Technologies Used

* **HTML5**
* **CSS3 (Flexbox & Grid)**
* **Google Fonts (Poppins)**

---

## 📁 Project Structure

```
portfolio/
│── index.html   # Main portfolio file
```

---

## 📌 Sections Overview

### 1. Header

* Name and professional title
* Call-to-action button (Contact Me)

### 2. About Me

* Brief introduction and career summary

### 3. Technical Skills

* Skills displayed as tags:

  * Programming: Python, Java, C++
  * Data: Pandas, NumPy, Scikit-learn
  * Web: HTML, CSS, JavaScript, Flask
  * Tools: Git, Power BI, Azure, MySQL

### 4. Projects

* AI-Based Fake News Detection
* Student Management System (CLI)
* Rule-Based NLP Chatbot

### 5. Certifications

* Microsoft Azure Fundamentals (AZ-900)

### 6. Currently Exploring

* Machine Learning, OS, Data Science, AI

### 7. Contact

* Email, Phone, LinkedIn, GitHub

### 8. Feedback Form

* User input form (name, email, message)
* Note: Backend functionality not implemented

## ⚙️ How to Run

1. Download or clone this repository:

   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```

2. Open the file:

   ```bash
   index.html
   ```

3. Run in any browser (Chrome, Edge, Firefox)

## ✨ Customization

* Update personal details in the HTML file
* Add more projects inside the `.card-container`
* Modify styles in the `<style>` section
* Connect the feedback form to a backend (e.g., Flask, Node.js)
